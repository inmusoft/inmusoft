Политика конфиденциальности «Фигурки из кубиков»

Действует с 28 октября 2026 г.

«Фигурки из кубиков» сами не собирают, не хранят на своих серверах и не передают третьим лицам персональные данные пользователя. Регистрация и вход в аккаунт не нужны. При этом приложение использует сторонние SDK — рекламный (VK Ads / myTarget), аналитический (MyTracker) и сервисы RuStore, — которые в рамках своих функций могут обрабатывать отдельные технические данные. Подробности — в разделах ниже.

Игровой прогресс

Собранные фигурки, монетки, полки, украшения, выбранная комната и настройки (например, звук) хранятся только на вашем устройстве. Разработчик не получает к ним доступа. Прогресс удаляется вместе с приложением или при очистке его данных в настройках устройства. Если на устройстве включено системное резервное копирование, данные приложения могут попадать в резервную копию вашего аккаунта — этим управляют настройки устройства, а не приложение.

Доступ к сети

Сама игра работает без интернета: файлы игры находятся внутри приложения. Доступ к сети нужен для загрузки и показа рекламы, для аналитики (см. ниже), для получения настроек приложения через RuStore Remote Config и для загрузки новых фигурок с сайта разработчика (GitHub Pages). При загрузке настроек и фигурок передаются только стандартные технические данные запроса (например, IP-адрес); игровой прогресс никуда не отправляется.

Вибрация

Приложение использует вибрацию устройства для коротких тактильных откликов в игре. Никакие данные при этом не собираются.

Реклама

Приложение показывает рекламу с помощью SDK VK Ads (myTarget), в том числе рекламу за вознаграждение: по вашему желанию можно посмотреть ролик и получить дополнительные игровые монетки. Реклама включается только после того, как вы приняли эту политику и Пользовательское соглашение на стартовом экране. Для показа рекламы и оценки её эффективности SDK может использовать рекламный идентификатор устройства и стандартные технические данные об устройстве и сети — независимо от Разработчика. Эти данные обрабатываются VK Ads в соответствии с их собственной политикой конфиденциальности: target.vk.ru/help/advertisers/privacy_policy. Сбросить рекламный идентификатор или отключить персонализацию рекламы можно в настройках устройства.

Аналитика

Чтобы понимать, откуда приходят игроки и как улучшать игру, приложение, начиная с версии 1.1.0, использует сервис аналитики MyTracker (ООО «ВК»). В более ранних версиях аналитики нет. Аналитика включается только после того, как вы приняли эту политику и Пользовательское соглашение на стартовом экране. MyTracker получает:

  • сведения об установке и запусках приложения, в том числе по какой рекламной ссылке оно было установлено;
  • обезличенные игровые события: собранная фигурка и полученные за неё монетки, просмотр рекламы;
  • стандартные технические данные об устройстве и сети и сбрасываемые идентификаторы (рекламный идентификатор, App Set ID, OAID).

Имя, номер телефона, адрес электронной почты и другие контактные данные приложение не собирает и в MyTracker не передаёт. Данные обрабатываются MyTracker в соответствии с его политикой конфиденциальности: tracker.my.com/ru/legal/privacy-policy. Сбросить рекламный идентификатор можно в настройках устройства.

Если приложение версии 1.1.0 или новее установлено из RuStore, оно один раз после установки получает через SDK RuStore Install Referrer сведения о рекламной ссылке, по которой была сделана установка (идентификатор ссылки и UTM-метки), и передаёт их в MyTracker.

Изменения политики

При изменении этой политики новая версия будет опубликована на этой странице, а в приложении появится запрос принять обновлённые условия.
